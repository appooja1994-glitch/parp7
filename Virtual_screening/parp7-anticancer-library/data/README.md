# data

`raw/` holds the downloaded source databases and is not tracked, because the
files are large and are reproducible with `scripts/00_fetch_sources.sh`.

Three files generated by the pipeline **are** tracked, and are the compound
set this repository deposits.

| File | Content |
|---|---|
| `total_molecules.smi` | Every compound assembled from the sources, before curation |
| `final_molecules.smi` | The curated screening library |
| `final_molecules_annotations.tsv` | Per compound provenance and annotation |

Both `.smi` files hold one compound per line as `SMILES<TAB>identifier`, with
a single comment line at the top. The annotation table is keyed on the same
identifier and carries the InChIKey, the contributing sources, the best
recorded activity in micromolar, the cell line it was measured against, the
PAINS flag and the number of sugars removed during curation.

Generate them with:

    bash run_all.sh

or, from an SDF you already have:

    python scripts/12_export_smi.py \
        --in data/anticancer_final.sdf \
        --out data/final_molecules.smi \
        --props data/final_molecules_annotations.tsv
